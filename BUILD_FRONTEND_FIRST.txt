NETWORK BACKBONE EXPLORER — CONTAMINATION LAB UPDATE (Oct 28, 2026)

A previous compiled frontend may not show the new Contamination Lab additions.
This ZIP includes updated React source and backend Python source. Rebuild the
frontend before running FastAPI, or use the updated START_CORRECTED_WINDOWS.bat.

One-time setup:
  cd frontend
  npm ci
  npm run build
  cd ..
  uv run uvicorn backend.main:app --port 8000

Alternative dev mode:
  uv run uvicorn backend.main:app --reload --port 8000
  cd frontend && npm ci && npm run dev
  Open http://localhost:5173

The built frontend is intentionally not bundled. The backend will not serve an
outdated interface. This development environment could not fetch npm packages,
so the React production build needs to be run on a machine with npm access.
